# AZ-900: Microsoft Azure Fundamentals — Learning Portfolio

Welcome to my Azure Fundamentals learning portfolio.

This repository documents my journey from cloud computing beginner to AZ-900 exam readiness, while developing practical foundational skills relevant to junior cloud support and cloud operations roles.

My approach combines structured learning, hands-on exercises, scenario-based problem-solving, exam practice, and project documentation.

## Learning Objectives

- Understand cloud computing concepts and terminology.
- Explain public, private, and hybrid cloud models.
- Understand IaaS, PaaS, and SaaS service models.
- Explore Azure architecture, compute, networking, and storage services.
- Understand identity, security, governance, compliance, and cost management.
- Practise troubleshooting and cloud operations scenarios.
- Build a documented portfolio demonstrating my understanding of Azure fundamentals.

## Portfolio Projects

The following projects will be developed as I progress through the course.

1. **Cloud Solution for a Small School** — Design a basic cloud solution and explain the benefits of cloud adoption.
2. **Azure Architecture Blueprint** — Document subscriptions, resource groups, regions, and core services.
3. **Identity and Security Plan** — Apply foundational concepts such as least privilege, Microsoft Entra ID, and Azure RBAC.
4. **Cloud Cost and Governance Plan** — Explore pricing estimates, resource tagging, budgets, and Azure Policy.
5. **Cloud Operations Incident Report** — Investigate a simulated cloud incident and document monitoring and recovery steps.

Project implementations will clearly distinguish between simulated exercises, architecture designs, and resources actually deployed in Azure.

## Learning Method

For each major topic, I aim to:

1. Learn the concept and explain it in my own words.
2. Identify the relevant Azure services and their use cases.
3. Complete an exercise or hands-on lab.
4. Answer exam-style questions and review mistakes.
5. Document practical lessons and troubleshooting scenarios.
